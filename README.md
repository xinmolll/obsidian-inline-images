# 图片存进笔记

An Obsidian plugin that stores image data directly inside Markdown notes.

把图片压缩后直接保存在 `.md` 文件中，无需单独的图片附件。支持桌面粘贴和拖入，也提供手机快捷菜单入口。

这是独立开发的第三方插件，与 Obsidian、GitHub 官方没有隶属关系。

## 安装

当前采用手动安装，尚未上架 Obsidian 社区插件市场。

1. 从本仓库的 Releases 下载 `inline-images-1.6.0.zip` 并解压。
2. 将 `inline-images` 文件夹放入笔记库的 `.obsidian/plugins/`。
3. 确认路径为 `.obsidian/plugins/inline-images/main.js`，不要重复套文件夹。
4. 重启 Obsidian，在「设置 → 第三方插件」中启用「图片存进笔记」。

更新时覆盖 `main.js`、`manifest.json`、`styles.css`，保留已有的 `data.json` 设置文件。安装插件不需要 Node.js。

## 使用

- **桌面添加图片**：在笔记编辑模式粘贴截图、拖入图片，或点击侧边栏的「添加图片到笔记」。
- **手机添加图片**：在编辑模式打开底部导航栏菜单，选择「添加图片到笔记」，直接打开选图器。
- **命令入口**：运行「图片存进笔记：选择图片，直接存进当前笔记」。
- **移动位置**：在编辑模式拖动图片，在同一篇笔记内调整位置。可撤销，不支持跨笔记拖动。
- **显示大小**：拖动图片右下角的缩放手柄，保持原比例。尺寸保存在笔记中，双击手柄可恢复自动大小。
- **大图预览**：双击图片放大，按 Esc、点击背景或关闭按钮退出。
- **删除图片**：点击「删除图片」，可用 `⌘Z` / `Ctrl+Z` 撤销。
- **旧笔记优化**：运行「优化当前笔记的图片性能」，减少旧版图片数据的换行数量。

手机和电脑必须分别安装或更新插件。手机原生附件按钮仍会遵循 Obsidian 的附件保存规则，本插件的菜单入口使用内嵌保存流程。

## 压缩和存储

默认照片编码质量为 90%，最长边为 3200 像素，不放大小图。PNG 截图尝试以至少 95% 质量编码为 WebP，并保留透明背景。只有压缩结果更小时才采用；解码或压缩失败时保留原图。可在设置中关闭压缩、调整质量或保留原始尺寸。

GIF、SVG、AVIF 以及检测到的 APNG/WebP 动画保留原样。支持的输入格式为 PNG、JPEG、GIF、WebP、AVIF、BMP 和 SVG。默认原始文件单张上限为 10 MB，可调整为 1–50 MB，一次总量最多 40 MB。

编码质量百分比是编码器参数，不表示按百分比保留画质。重新编码 JPEG 会移除 EXIF 等元数据；原始图片文件不会被修改。

图片以专用代码块存储，示意如下；示意内容不是真实图片编码：

````markdown
```inline-image
{"name":"photo.jpg","mime":"image/jpeg","width":480}
...完整的 Base64 图片数据...
```
````

代码块数据行最多 4096 字符。显示层使用短期内存图片地址和引用计数缓存；这些地址不会替代 Markdown 中的完整图片数据，也不会生成图片附件。选择图片时如果切换笔记或修改正文，插入会取消，以避免写错位置。

## 限制与兼容性

- **需要本插件显示图片**：其他 Markdown 软件通常会显示代码块；停用插件后，图片数据仍在笔记中，但不会自动显示。
- **大文件仍有编辑开销**：Base64 通常比原图大约三分之一，多张大图会影响输入、同步和版本管理。现有优化不能保证所有插件组合下输入完全流畅；可以先写文字，再添加图片。
- 只处理新插入的图片，不自动转换或删除已有的图片附件。调整显示尺寸不会重新压缩。
- 网页复制内容如果只有远程图片链接，没有图片文件，不会自动下载。
- 插件未实现网络请求、遥测或账号登录功能。笔记自身的云端同步由 Obsidian 或其他同步工具处理。
- 最低 Obsidian 版本为 1.5.0。已在手机和 macOS 上测试（手机测试由使用者实际使用反馈确认；macOS 曾在 Obsidian 1.13.7/1.14.5 中检查）。这不代表已覆盖所有手机型号和系统版本；iPad 与 Windows 尚未完成系统性实机验证。

## 开发

开发环境：Node.js 22.13 或更高版本，pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm run check
pnpm test
pnpm run build
```

源码位于 `src/`，自动检查位于 `tests/`。当前包含 25 项检查，覆盖编码、压缩决策、动画识别、编辑保护、移动、尺寸元数据、内存缓存和菜单选图流程。模拟接口检查不等于手机实机验证。

构建时将 Obsidian 和 CodeMirror 标记为外部依赖，使用应用提供的实例。仓库不包含笔记库、个人图片、账号配置或本机调试截图。
